Setup & permissions

Install it, wire it, hand out roles.

The sub-ten-minute path from a fresh Odoo to a published Vinc card. Everything below is enforced at the ORM layer, not the UI.

1 · Install

  • pip install -r requirements.txt (installs qrcode, Pillow, openpyxl)
  • Drop qr_code_odoo/ in your addons_path
  • Restart Odoo, then Apps → Update Apps List → search "Vinc" → Install

2 · Configure the instance

  • Settings → Technical → System Parameters → web.base.url — set to your public HTTPS host. All QR links, emails, magic-link activations reference this.
  • Settings → Technical → Outgoing Mail Servers — configure SMTP. Lead notifications, intro / digest / leadback emails and bulk-onboarding activation mails queue through mail.mail.
  • Multi-website? Pick which website hosts /get-started, /vinculum/guide, /bulk-onboard.

3 · Two roles, enforced by record rules

  • Regular internal user (base.group_user) — sees only records they created. No access to bulk.onboarding.*.
  • Vinc Manager (qr_code_odoo.group_vinc_manager) — sees every card, lead and tracking row on the instance. Required to run /bulk-onboard.
  • Odoo administrators (base.group_system) implicitly get Vinc Manager via implied_ids.

4 · Grant the manager role

  • Settings → Users & Companies → Users → pick the user → Access Rights tab → Vinc → Vinc Manager → Save.
  • Everyone else stays scoped to their own records via ir.rule.

Public vs authenticated routes

  • Public: /<slug>, /create_lead, /create_review, /create_service_request, /vcard/qr_code/download/<id>, /nfc/setup/<id>, /vinculum/guide, /bulk-onboard/activate/<token>
  • User: /get-started, /vcard/submit, /vcard/preview
  • Vinc Manager only: /bulk-onboard, /bulk-onboard/upload, /bulk-onboard/submit

Optional: self-serve signup

Install Odoo's auth_signup module and new signups land as base.group_user — zero access to existing cards thanks to the record rules. They can create their own via /get-started. Promote to Vinc Manager manually if wanted.

FAQ

The questions we hear most often.

Licensing, activation, updates, support. If your question isn't here, email support@getvinc.com and a real person replies.

Where do I get my license key?

After purchase on the Odoo App Store, you'll receive a license key by email within a few minutes. The same key is also available in your apps.odoo.com purchase history.

Inside Odoo, go to Vinc → Settings → License and paste the key. Activation is instant; you'll see a green "License active" badge and the dashboard will unlock.

My license isn't activating — what now?

The two common causes:

1. Outbound HTTPS is blocked. License validation calls license.getvinc.com. If your Odoo server can't reach it, activation fails. Allow outbound HTTPS on port 443 and retry.

2. Clock skew. License tokens are time-signed. If your server clock is more than 5 minutes off UTC, validation rejects. Sync via NTP and retry.

Still stuck? Send your Odoo version + the error message to support@getvinc.com — response within one business day.

How many Odoo databases can I use one license on?

One license = one production Odoo database. You can also activate it on one staging / test database without extra cost — we don't count non-production environments.

Running multiple separate production tenants? Contact sales for a multi-DB license bundle.

What happens if my license expires or I transfer to a new server?

The license is a one-time purchase, not a subscription — it doesn't expire. Future module updates are included for the lifetime of the product.

To move the module to a new Odoo server, deactivate the license on the old instance (Vinc → Settings → License → Deactivate), then activate on the new one with the same key. Takes a minute.

Can I migrate from Vinc SaaS to this self-hosted module?

Yes. Export your cards, leads, and reviews from your Vinc SaaS account (Settings → Export data), install this module on your Odoo instance, and import via the bulk-onboarding wizard. Lead history imports via CSV.

For large migrations (50+ cards), we'll run it with you on a call — email support to schedule.

Which Odoo versions are supported?

Vinc for Odoo targets Odoo 17.0 (Community and Enterprise). Earlier versions aren't supported — Odoo 16 and earlier lack the QWeb / OWL features Vinc relies on.

Odoo 18 compatibility is on the roadmap and will ship as a free update to existing license holders.

Do I need any external services to make it work?

Core Vinc runs entirely inside your Odoo. No external dependencies.

Two optional integrations unlock extra features: an outgoing SMTP server (for intro emails, lead notifications, and digest emails) and an IP geolocation service (Vinc uses the free geojs.io / ip-api.com tiers automatically — no key required). Everything else is self-contained.

Does this replace my Odoo CRM, or sit alongside it?

Sits alongside. Vinc writes captured leads directly into crm.lead as opportunities, using your existing pipeline stages, teams, and routing rules. Nothing about your CRM setup changes.

Each captured lead gets a partner_vcard_id backref so you can filter the pipeline by "leads from Vinc" whenever you want.

How are module updates delivered?

New versions ship through the Odoo App Store. You'll see an "Update available" badge next to Vinc in your Apps list. Click Upgrade — the usual Odoo update flow.

Updates never touch your data. Your cards, leads, and settings stay exactly as you left them.

Odoo App Store handles refunds within 14 days of purchase, no questions asked. Request via your apps.odoo.com purchase history or email support@getvinc.com.

Past the 14-day window, we'll still consider fair refund requests on a case-by-case basis — just tell us what went wrong.

Can I modify the module's source code?

Yes — the license permits modification and extension for your own use. What you can't do: redistribute, resell, or sublicense the modified module to third parties.

Contributing a useful patch back to the project is welcome; email a pull request or a diff to support@getvinc.com.
